# Tableau dashboard guide

These CSVs are generated by `python run_pipeline.py` and are ready to drop into
[Tableau Public](https://public.tableau.com) (free). The goal is one published
workbook with three dashboards, linked from the main README.

| File | Grain | Use it for |
|---|---|---|
| `player_season.csv` | one row per player per season | value scatter, leaderboards |
| `player_gameweek.csv` | one row per player per gameweek played | form trends |
| `team_season.csv` | one row per team per season | attack vs defence quadrant |
| `model_predictions_2025_26.csv` | one row per player per gameweek, test season | model scorecard |

## Setup (5 minutes)

1. Install Tableau Public and sign in.
2. **Connect → Text file** → pick `player_season.csv`. Add the other three files as
   *separate data sources* (Data → New Data Source). They don't need joining.
3. In each source, check that `season` is a String (Abc) and `gw` is a Number.

## Dashboard 1: Value Finder

**Question it answers:** which players give the most points for their price?

Sheet "Value scatter" (source: `player_season`)
1. Columns: `AVG(avg_price)`. Rows: `SUM(total_points)`.
2. Drag `player` to **Detail**, `position` to **Color**, `avg_ownership_pct` to **Size**.
3. Filters: `season` (show filter, single value dropdown), `minutes` ≥ 900.
4. Analytics pane → drag **Trend Line** (linear) onto the view. Players above the
   line beat their price.
5. Create a calculated field **Points vs Expected for Price** to colour outliers later:
   ```
   SUM([total_points]) - WINDOW_AVG(SUM([total_points]))
   ```

Sheet "Top differentials" (source: `player_season`)
1. Rows: `player`. Columns: `SUM(total_points)`. Sort descending.
2. Filter `avg_ownership_pct` < 5 and the same `season` filter (Apply to Worksheets →
   All using this data source).
3. Keep the top 10 (Filter on `player` → Top → By field → 10 by `total_points`).

Dashboard: put both sheets side by side, season filter across the top.

## Dashboard 2: Team Attack vs Defence

Sheet "Quadrant" (source: `team_season`)
1. Columns: `SUM(xg_for)`. Rows: `SUM(xg_against)`; right-click the Rows axis →
   **Reversed** so good defences sit at the top.
2. `short_name` to **Label**, `season` as a filter.
3. Analytics → **Average Line** on both axes to split the view into four quadrants.
4. Tooltip: add `finishing_vs_xg` with the text "Goals above/below xG: <value>".

Sheet "Finishing luck": bar chart of `finishing_vs_xg` by `team`, sorted, with a
diverging colour (Edit Colors → Orange-Blue Diverging, centre 0).

## Dashboard 3: Model Scorecard

**Question it answers:** how good is the model, gameweek by gameweek?

Sheet "Predicted vs actual" (source: `model_predictions_2025_26`)
1. Filter `regular_starter` = True.
2. Columns: `gw` (dimension, continuous). Rows: `AVG(predicted_points)` and
   `AVG(actual_points)`; right-click the second axis → **Dual Axis** → **Synchronize Axis**
   (same scale, so it is a fair comparison).

Sheet "Error by position"
1. Rows: `position`. Columns: `AVG(error)`.
2. Note for the caption: defenders are under-predicted because 2025-26 introduced
   defensive contribution points, which the training seasons never saw.

Sheet "Player lookup"
1. Rows: `player`, `gw`. Columns: `SUM(predicted_points)`, `SUM(actual_points)` as a table.
2. Add `player` as a filter with **Wildcard match** so recruiters can type a name.

## Publish

File → Save to Tableau Public. Copy the link and paste it into the main README
under "Interactive dashboard". Take a screenshot of each dashboard and save it as
`reports/figures/tableau_<name>.png` so the README still shows something if the
link is slow.
